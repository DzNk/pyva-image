# Proposal

## Why

Текущий неизменяемый тег показывает точный патч CPython и только мажорную версию Java. При выборе образа из реестра полная версия Temurin нужна для проверки, какой патч и какой upstream build попадут в приложение.

## What Changes

- Добавить версию и номер сборки Temurin из `java_runtime.json` в неизменяемый тег. Например, `3.14.10-java25.0.5.1_2-debian13-<UTC>-g<SHA>` обозначает Temurin `25.0.5.1+2`.
- Сохранить каналы семейств, например `3.14-java25-debian13`, и все предыдущие неизменяемые ссылки. Глобальный тег `latest` отсутствует.
- **BREAKING** для скриптов, которые вычисляют имя нового неизменяемого тега по старому шаблону. Для публикации источником точного имени служит итог Actions, для потребителей доступны каналы и digest.
- Проверить ручной запуск обновления в Actions и совпадение опубликованных тегов с JVM на обеих архитектурах. Сценарий появления нового патча проверяется на тестовых метаданных, если upstream пока поставляет сохранённые версии.

## Impact

Формирование имени в `image_manifest.py` и `release.sh`, проверки Java, регрессии публикации и документация. Публикацию и продвижение каналов выполняет существующий GitHub Actions workflow.
